# Dashboard Cards

Edit `cards.yaml` to control the swipe card on the app dashboard.

- Add a new item to `topics` for each vertical swipe topic.
- Add a new item to `slides` for each horizontal swipe card inside that topic.
- Use `imagePath` for repo files, such as `design/course-icons/java.png`.
- Use `imageUrl` only when the image is already hosted elsewhere.
- The app currently supports these display templates: `Text`, `Image + Text`, and `Image`.
