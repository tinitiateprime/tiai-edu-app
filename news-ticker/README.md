# News Ticker

This folder stores the top ticker content for the website.

## Supported Ticker Types

- jobs
- trending technologies
- TinitiateAI events

## Structure

- `feed.json`

## How To Add A New Ticker Item

1. Add a new object in `feed.json`
2. Set a unique `id`
3. Choose `kind`
4. Provide `label`, `title`, `href`, and `priority`
